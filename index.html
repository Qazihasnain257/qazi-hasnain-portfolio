AI Smart Security Robot

The AI Smart Security Robot is an autonomous surveillance robot designed for indoor security. It uses an ESP32-CAM for live video streaming, an ultrasonic sensor for obstacle avoidance, and Python with OpenCV for AI-based person detection. When a person is detected, the system generates an alert while the robot continues its surveillance patrol.
